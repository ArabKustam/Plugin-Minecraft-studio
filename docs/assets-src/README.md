# README artwork sources

Every image under `docs/images/readme/` is generated by code from the real Industrial Reactor demo. None of it is hand-drawn mock-up art.

| Script | Output |
|---|---|
| `build.mjs` | `banner-{en,ru}.png`, `panel-{1..5}-{en,ru}.png`, `how-it-works-{en,ru}.png`, `social-preview.png`, `reactor-states-{en,ru}.gif` |
| `capture-tour.mjs` | `dashboard-tour.gif`. Records the live dashboard through Chrome DevTools; needs Chrome and FFmpeg. |
| `pixelfont.mjs` | The project's own 5×7 pixel font (Latin, Cyrillic, digits) used by the artwork |
| `../../scripts/gallery.mjs` | `docs/images/texture-*.png`, `model-*.png`, `animation-*.png`, `logo.png` |
| `../../scripts/screenshot-dashboard.mjs` | `docs/images/dashboard-*.png` |

## Regenerate

1. Run `node examples/industrial-reactor/studio/produce.mjs --fresh`. The rest depends on its output.
2. Run `node scripts/gallery.mjs`.
3. Run `node docs/assets-src/build.mjs`.
4. Run `node docs/assets-src/capture-tour.mjs`.
5. Start the dashboard on the demo, then run `node scripts/screenshot-dashboard.mjs --url http://127.0.0.1:4777`.

## Visual language

| Element | Choice |
|---|---|
| Palette | night `#0c0e12`, surface `#151920`, grass `#5ccf6a`, dirt `#794f2f`, steel `#6c7683`, hazard `#d9b42a`, teal `#3fb0c8`, text `#e8ebf1` |
| Type | the original pixel font, with a hard Minecraft-style drop shadow |
| Shapes | square blocks, 4 px frames, hazard stripes, a grass edge over an industrial floor tiled from the demo's own textures |
| Mood | an industrial Minecraft production studio with a dark UI, matching the dashboard theme |
